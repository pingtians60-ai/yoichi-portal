# 🏮 夜市 (Yoichi) Portal - GAS公開・完全ガイド

Google Apps Script (GAS) を使うことで、**サーバー代・ドメイン代不要（完全無料）** で「夜市ポータル」アプリをWeb上に公開し、Googleスプレッドシートとリアルタイムに同期させることができます。

---

## 🚀 5分で完了！公開手順（ステップ・バイ・ステップ）

### ステップ 1: 新しいGoogleスプレッドシートを作成
1. ブラウザで [Googleスプレッドシート](https://sheets.google.com/) にアクセスし、**「空白のスプレッドシート」** を新規作成します。
2. スプレッドシートのタイトル（左上）を `夜市ポータル` など好きな名前に設定します。
   > [!NOTE]
   > スプレッドシート内のシート（タブ）や見出し行は、スクリプトが初回起動時に自動作成するため、最初は完全に空のままで大丈夫です。

---

### ステップ 2: Apps Script エディタを開く
1. スプレッドシート上部のメニューから **「拡張機能」** ➔ **「Apps Script」** をクリックします。
2. Apps Script のエディタ画面が開きます。

---

### ステップ 3: スクリプトとHTMLをコピー＆ペースト

GASプロジェクトには **2つのファイル**（`コード.gs` と `index.html`）を配置します。

#### ① `コード.gs` の貼り付け
1. 画面左側の「ファイル」一覧にある `コード.gs` を選択します。
2. 最初から書かれているコード（`function myFunction() { ... }`）をすべて消して空にします。
3. このリポジトリの [gas/Code.gs](file:///c:/Users/pingt/OneDrive/WCP/夜市HP/gas/Code.gs) の内容を **すべてコピー** して貼り付けます。
4. `Ctrl + S`（Macは `Cmd + S`）または上部のフロッピーディスクアイコンを押して保存します。

#### ② `index.html` の作成と貼り付け
1. 画面左側の「ファイル」の右側にある **「＋」（ファイルの追加）** ➔ **「HTML」** をクリックします。
2. ファイル名に **`index`** と入力して Enter を押します（自動的に `index.html` になります）。
3. 最初から書かれているHTMLをすべて消して空にします。
4. このリポジトリの [gas/index.html](file:///c:/Users/pingt/OneDrive/WCP/夜市HP/gas/index.html) の内容を **すべてコピー** して貼り付けます。
5. `Ctrl + S`（Macは `Cmd + S`）を押して保存します。

---

### ステップ 4: ウェブアプリとしてデプロイ（公開）
1. 画面右上にある青いボタン **「デプロイ」** ➔ **「新しいデプロイ」** をクリックします。
2. 左上の歯車アイコン ⚙（種類の選択）をクリックし、**「ウェブアプリ」** を選択します。
3. 以下の設定を行います：
   - **説明**: 例: `夜市ポータル 本番公開 v1`
   - **次のユーザーとして実行**: **「自分」**（あなたのGoogleアカウント）
   - **アクセスできるユーザー**: **「全員」**（Anyone）
   > [!IMPORTANT]
   > 「アクセスできるユーザー」を必ず **「全員」** にしてください。「自分のみ」などにすると、他のメンバーがアクセスした際にログイン画面や権限エラーになってしまいます。
4. 右下の **「デプロイ」** ボタンをクリックします。

---

### ステップ 5: 初回アクセス権の承認 (Googleアカウントの許可)
初回デプロイ時のみ、スプレッドシートへのアクセス許可が求められます。

1. ポップアップ画面が表示されたら **「アクセスを承認」** をクリックします。
2. ご自身のGoogleアカウントを選択します。
3. 「このアプリは Google で確認されていません」という警告画面が出た場合：
   - 左下の小さな文字 **「詳細」**（または「詳細を表示」）をクリックします。
   - 展開されたリンク **「夜市ポータル（安全ではないページ）に移動」** をクリックします。
4. アクセス権のリクエスト画面で **「許可」** をクリックします。

---

### ステップ 6: 公開完了！URLにアクセス
1. デプロイ完了画面に **「ウェブアプリ」** の **「URL」** が表示されます。
   - 例: `https://script.google.com/macros/s/AKfycb.../exec`
2. **「コピー」** をクリックし、ブラウザの新しいタブで開いてみてください。
3. 🎉 **夜市ポータルがGAS上で直接起動し、自由に利用できます！**
   - スマホやPCのブラウザからURLを開くだけで、メンバー全員でスケジュールやシフトの共有・編集が可能です。
   - スケジュールや名簿を編集すると、連動してGoogleスプレッドシートに自動保存されます。

---

## 💡 アプリのコードやデザインを更新したい場合

デザイン（CSS）や機能（JS）、HTMLを変更した場合は、以下の手順でGASへ反映できます：

1. ローカル環境でファイルを編集後、PowerShellでバンドルスクリプトを実行：
   ```powershell
   powershell -ExecutionPolicy Bypass -File .\build-gas.ps1
   ```
2. 自動生成された `gas/index.html` の中身をコピーし、GASエディタの `index.html` に上書き貼り付けして保存します。
3. GASエディタ右上の **「デプロイ」** ➔ **「デプロイを管理」** ➔ 鉛筆アイコン ✏（編集）をクリックし、バージョンを **「新バージョン」** にして「デプロイ」をクリックします。
   （※URLを変えずに最新版へアップデートできます）

---

## ❓ トラブルシューティング

- **画面が真っ白、またはロード中が終わらない場合**:
  - `gas/index.html` を作成する際、ファイル名が `index`（拡張子を除いた名前）になっているか確認してください。
- **データが保存されない・同期エラーになる場合**:
  - デプロイの「アクセスできるユーザー」が「全員」になっているかご確認ください。
  - スプレッドシートの権限でエラーが出ている場合、GASエディタで `testInitialize` 関数を手動実行してアクセス許可を再確認してください。
